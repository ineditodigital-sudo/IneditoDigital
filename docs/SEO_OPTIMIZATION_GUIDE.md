   ```
   URL: /admin
   Usuario: admin
   Contraseña: @Inédito%131415
   ```

2. **Accede a SEO**
   - Click en "SEO y Metadatos" en el menú lateral

3. **Selecciona la Página**
   - Pestaña "Páginas"
   - Elige la página del dropdown

4. **Edita los Campos**
   - **Título:** Máximo 60 caracteres (contador incluido)
   - **Descripción:** Máximo 160 caracteres
   - **Keywords:** Separa con comas
   - **Canonical:** URL completa
   - **Imagen OG:** URL de la imagen

5. **Guarda Cambios**
   - Click en "Guardar Cambios"
   - Verás confirmación verde

6. **Verifica en el Sitio**
   - Navega a la página
   - Click derecho → "Ver código fuente"
   - Busca `<title>` y `<meta name="description">`

## 📊 Checklist de Verificación SEO

### Para Cada Página Nueva

- [ ] Título único de 50-60 caracteres
- [ ] Descripción única de 150-160 caracteres
- [ ] 6-10 keywords relevantes
- [ ] URL canónica configurada
- [ ] Imagen OG definida
- [ ] H1 incluye keyword principal
- [ ] Contenido mínimo 300 palabras
- [ ] Internal links a páginas relacionadas
- [ ] CTA claro y visible
- [ ] Mobile responsive
- [ ] Velocidad de carga < 3 segundos

### Antes de Publicar

- [ ] Verificar título en Google Search Preview
- [ ] Verificar descripción en Google Search Preview
- [ ] Probar en GTMetrix o PageSpeed Insights
- [ ] Verificar en Mobile-Friendly Test de Google
- [ ] Probar Schema Markup en Google Rich Results Test
- [ ] Verificar que Analytics esté trackeando
- [ ] Revisar que no haya errores 404
- [ ] Verificar que imágenes tengan alt text
